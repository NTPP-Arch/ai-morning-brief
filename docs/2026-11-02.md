**关键细节**：训练先经过课程式监督微调，逐步把 token 层面的推理转换为潜在推理；随后用基于信息增益的强化学习，使潜在推理在没有真实标注答案监督的条件下继续演化。这不是简单延长文字思维链，而是改变推理所在的表示空间，以缓解离散 token 对连续生成过程形成的瓶颈。作者在多种文生图基准上报告了生成质量、提示词遵循和组合保真度的改善。在 GenEval 上，LARC 比 BAGEL 高 7 个百分点；在并行和顺序两种测试时扩展策略下，它也优于基于 token 的生成方式。这里的“扩展”指测试阶段增加计算时观察到的表现变化，不等同于训练更多模型参数。

### 深读｜Flide：决策查询最高提速 9.5 倍，同时保留精确分支语义

**发生了什么**：Flide 面向代理系统中的决策模型推理：这类模型要快速回答类别选择问题，而不是持续生成长文本。论文针对现有生成式推理引擎在此类请求上重复计算前缀、或改变输出概率的问题，设计了专门的执行方式。

**关键细节**：Flide 将一次决策请求的逻辑树，与实际执行所用的单条扁平 token 流分开，避免把每个查询分支都当成独立的完整请求。其 ForkAttention 通过驻留 GPU 的索引追踪分支依赖，覆盖标准注意力层和循环式 Gated DeltaNet 层。作者给出的保证是：在精确算术下，每个分支的计算结果与单独进行一次前向传播相同。分支拓扑写在 GPU 元数据中，因此混合请求可以共用一组紧凑的预录制执行图；不断增长的代理历史也能从先前保存的检查点继续计算。在公开的混合模型和决策模型评估中，Flide 回答查询的速度最高达到 vLLM 和 SGLang 的 9.5 倍；按总变差距离衡量，其结果也最接近 float32 参考值。

**⚠️ 边界**：“精确”是精确算术下的分支等价保证，不是浮点硬件上逐位相同的承诺；论文因此另用 float32 参考值比较数值偏差。最高 9.5 倍是评估中出现的上限，不能当作任意模型、请求组合和部署环境的稳定加速比。

**一句话点评**：我认为它抓准了决策模型的部署矛盾：要缩短延迟，不能以悄悄改变分支概率为代价；可核对的执行语义比单纯报吞吐更有说服力。

### 深读｜ZHA：树形索引让注意力整体达到次二次增长

**发生了什么**：Zyphra Hierarchical Attention（ZHA）提出用分层树形索引挑选需要参与注意力计算的键，处理长上下文中注意力成本随序列长度二次增长的问题。论文特别指出，只稀疏化最终注意力还不够：如果负责找出稀疏位置的索引器仍是二次成本，整体增长阶并不会改变。

**关键细节**：ZHA 在 KV 缓存上递归压缩键的摘要，构建一棵树；后续查询从树顶向下遍历，取出少量键，再对所选位置执行注意力。随着序列变长，方法通过逐步增加树深，使路由与最终注意力的合计成本相对序列长度呈次线性增长，进而使整体注意力成本呈次二次、但仍超线性的增长。作者称，现有预训练模型只需在数十亿 token 上进行一段较短的 KL 蒸馏训练，就能应用该方法。论文报告，长上下文检索，以及推理、数学和代理编程评估中的表现得以保持；树的几何形状改变时也较稳健，包括深至 6 层的树。性能模型显示，它在超过 100 万 token 的上下文中可显著胜过所比较的方法，并指向数亿乃至数十亿 token 的潜在有效窗口。

**一句话点评**：我认为这篇的关键不是又做了一种稀疏注意力，而是把“找哪些位置”本身算进复杂度；能否守住这笔索引账，决定长上下文方案是否真能扩展。

### 深读｜CRoS：打乱思维步骤顺序，未见任务准确率达 46.8%

**发生了什么**：CRoS 试图改进思维链训练奖励的一个漏洞：答案答对，并不证明写出的推理过程对答案起了因果作用。论文提出通过打乱推理步骤的顺序来测试这种作用，尽量避免删除步骤或注入错误时同时改变步骤所含信息。

**关键细节**：常见可验证奖励强化学习主要奖励最终答案正确；已有因果性指标则观察模型在推理步骤被扰动后是否改答案。若扰动同时删掉信息，模型对信息缺失的敏感性就可能被误认为对推理顺序的依赖；把这类指标直接当奖励，还可能鼓励信息更少、探索和自我纠错更弱的思维链。CRoS 保留各步骤内容，只改变排列次序，利用答案变化形成因果性奖励。在 Reasoning Gym 上以 Gemma-3-4B 实验时，它在五个未见过的逻辑与游戏数据集上取得 46.8% 准确率，最强对照为 43.8%。CoT-Pass@K 从 K=1 到 128 均领先对照，平均为 43.4% 对 41.4%；提示承认得分为 34.0% 对 20.2%。

**⚠️ 边界**：保留步骤内容并不保证打乱后仍构成自然、可执行的推理；这一指标减少的是“改动步骤信息”造成的混杂，不能单凭分数证明完整因果机制。所列数字来自指定模型、训练设置和评估任务，不宜推广为所有思维链训练的固定增益。

**一句话点评**：我赞成把奖励从“写了像推理的话”推向“步骤顺序确实影响答案”；但打乱测试更适合作为有针对性的约束，而不是推理真实性的最终裁判。

**⚠️ 边界**：驻场评估尚无统一的访问范围、结果报告标准或稳定资助制度，许多运作细节仍在制定。由被评估公司直接出资，不能单凭“独立”一词消除利益冲突疑问；公告也没有把双方的投入承诺写成单笔评估合同金额。

**一句话点评**：我支持把评估者带进模型开发过程，但判断这项试点是否真正独立，关键要看他们最终能看到什么、能公开什么。

来源：anthropic.com

### METR 开始获得员工级访问权限，风险评估结果拟公开

**发生了什么**：Anthropic 宣布，已开始向非营利前沿 AI 评估机构 METR 的一个团队提供与员工相近的访问权限。METR 将公布其风险评估结果。

**关键细节**：Anthropic 表示，上个月已承诺加强对模型及安全实践的独立第三方评估，并签署了《白宫超级智能协议》；该协议包含企业与独立外部审计者或评估者合作的承诺。此次进展从合作承诺走向人员访问，但公告使用的是“已开始提供”权限，并非宣称全部评估工作已经完成。双方也不是初次接触：过去一年，METR 已参与 Anthropic 多份《风险报告》的审查。除 METR 外，Anthropic 还在与 SecureBio 和埃森哲开展评估合作，并与包括 Hugging Face 在内的其他机构进行初步讨论。把已开始访问的 METR、正在合作的评估者，以及仍处于讨论阶段的机构分开看，才能看清这些安排各自的进度。

**⚠️ 边界**：公告未列出 METR 团队现阶段可访问的具体材料，也未给出风险评估结果的发布日期。因此，“员工级访问”不能直接理解为已取得公司内部所有信息；与 Hugging Face 的初步讨论，也不能写成已达成评估合作。

**一句话点评**：我认为公开风险评估结果是这项安排最可检验的承诺；在结果和访问范围披露前，合作机构名单本身不足以证明监督力度。

来源：anthropic.com

### Claude Frontier Academy 获 1 亿美元承诺，目标培训 1 万名部署工程师

**发生了什么**：Anthropic 宣布启动 Claude Frontier Academy，以人才培养回应企业部署 AI 的需求。公司提出投入 1 亿美元，并计划在 2027 年底前培训 1 万名 Frontier Deployed Engineers，即前沿部署工程师。

**关键细节**：公告称，学院将以 Anthropic 自身工程师所用的技能标准训练这类人员，培训对象聚焦于把 AI 能力带进实际部署工作的工程师。首批学员来自埃森哲、贝恩、凯捷、澳大利亚联邦银行、德勤、麦肯锡、摩根士丹利和诺和诺德等机构。这份名单同时包含咨询与专业服务机构、银行和其他企业：公告交代的是工程师来自哪些机构，而不是这些机构各自会部署多少系统。1 万名是截至 2027 年底的培训目标，不是已完成人数；1 亿美元是公司对项目的投入承诺，也不是已发生的培训支出。把技能标准、培训目标和首批来源分开，才能准确理解这次发布所处的阶段。

**⚠️ 边界**：公告摘录没有给出课程时长、考核办法、结业人数，也没有说明培训后实际部署的成效。“采用与 Anthropic 工程师相同的技能标准”不能直接等同于学员已具备相同经验，或其所在机构已完成企业级落地。

**一句话点评**：我认为 Anthropic 把部署人才当作产品扩张的配套能力来建设；目标能否兑现，应看培训完成和实际部署，而非只看首批机构阵容。

来源：anthropic.com
